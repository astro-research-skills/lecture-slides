# Worked example — figure sources

Every asset in `assets/` is here, and nothing is on a slide that is not here. All five are
`[course]` schematics generated by `make_figures.py` in this directory: they are pictures of
*this skill's own rules*, not measurements of anything, and each slide's caption says so.
There is no third-party figure in this example, so there is no licence to trace — which is
itself the point of the `[course]` tag: a schematic you can regenerate needs no permission
and carries no doubt about what the data are.

```
python3 make_figures.py          # regenerates all five; needs matplotlib
```
